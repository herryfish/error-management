# ADR 0001: 多题拍照选择导入架构与冲突处理策略

## 状态
已通过 (Accepted)

## 上下文 (Context)
学生在日常学习中，常常拍照整页试卷或作业（包含多道错题）。原有的单题拍照识别流程无法高效处理多题录入。需要在 H5 端提供整页识别、多题切分、勾选预览与批量导入能力。

## 决策 (Decisions)

1. **切分与识别机制（AI 预切分 + 人工微调）**：
   - 采用大模型 Vision 能力进行整页多题坐标与内容识别（返回题目几何区域与识别文本）。
   - 前端 H5 界面在图片上动态绘制识别框，允许学生勾选、增加/删除框或微调边界。

2. **查重与冲突处理（标记并允许覆盖）**：
   - 在多题确认列表中，系统基于文本指纹比对数据库。
   - 对已存在的错题打上“已录入”标识并默认取消勾选，允许学生点击查看原题或勾选强制覆盖更新。

3. **属性分配策略（AI 默认识别 + 卡片独立微调）**：
   - 题目科目、题型与难度默认由 LLM 自动推导填充。
   - 批量预览列表中暴露独立下拉框，允许学生对个别题目属性进行微调。

4. **数据写入机制（原子事务）**：
   - 批量导入 API 使用数据库 Transaction 事务，确保多道错题及其对应 `Mastery` 初始记录要么全量保存成功，要么整体回滚。

## 后果 (Consequences)
- **正面**：极大提升多题录入效率，保障数据强一致性，避免重复错题污染。
- **负面**：前端需要增加图片 Canvas/SVG 选框渲染组件，整页图像 Vision 识别的 Token 消耗相对高于单题识别。
