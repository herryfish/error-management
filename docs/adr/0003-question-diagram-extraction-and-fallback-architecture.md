# ADR 0003: 错题插图自动提取、容错降级与生命周期管理架构

## 状态
已通过 (Accepted)

## 上下文 (Context)
学生录入的数理化错题中经常包含几何图形、函数图像、物理电路图等关键解题插图。原全景拍照图可能带有手写批改或笔记，直接在作答/重做时暴露全景图容易泄露答案，且混杂无关背景。因此需要将题目中的独立插图自动识别、剪裁并单独存储展示。

## 决策 (Decisions)

1. **插图识别与提取机制（Vision Bbox + Sharp 自动剪裁）**：
   - 在识别接口中由 Vision 模型返回插图二维坐标数组（`diagramBboxes`）。
   - 后端基于坐标使用 `sharp` 对原始全景图进行自动剪裁，生成独立插图并保存为插图数组 (`diagramUrls: string[]`)。

2. **容错降级策略（Fallback Strategy）**：
   - 若模型判定有插图但自动剪裁异常（坐标越界或生成失败），系统自动降级裁剪题目包含区域的局部原图作为替代，确保解题要素不缺失。

3. **交互与展现约束（Redo & Collapsible Rule）**：
   - **重做场景**：在「在线重做」界面允许渲染精准剪裁的插图数组 `diagramUrls`（题干必要条件），但依然禁止暴露原始全景图 `imageUrl`。
   - **详情场景**：题目详情页默认将包含手写笔记的全景图设为折叠，插图卡片独立展示。
   - **微调契机**：现阶段前端采取整重拍策略，画框拖拽微调作为后续 V2 升级保留项。

4. **存储与生命周期管理（Disk Clean-up Lifecycle）**：
   - 删除错题记录时，后端触发级联清理任务，自动从磁盘/对象存储中删除该错题关联的 `diagramUrls` 文件。

## 后果 (Consequences)
- **正面**：在重做练习时既能看到清晰的解题插图，又消除了全景图中手写答案的提示隐患，提升了答题专注度。
- **负面**：增加了后端图像处理与存储空间消耗。
