# Triage Label Vocabulary

This repository uses the canonical five-label triage vocabulary.

| Label | Purpose |
| :--- | :--- |
| `needs-triage` | Newly opened issues awaiting initial evaluation. |
| `needs-info` | Issues waiting for additional information or user clarification. |
| `ready-for-agent` | Issues triaged and scoped, ready for AI agent execution. |
| `ready-for-human` | Issues requiring human intervention, high-risk approvals, or manual review. |
| `wontfix` | Out-of-scope or rejected issues. |
