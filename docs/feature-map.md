# 错题管理系统 功能地图（Feature Map）

> **视角**：用户视角的功能版站点地图——从入口出发，按「入口 → 功能域 → 功能点」三层组织，每个功能点一句话说明。
> **口径**：以 v1.4.0 功能分支（DC-468）实现为准如实盘点，**不含未实现功能**。规划中项（P3 变式练习触发链路调整、FSRS 默认启用）见文末「规划中」注记。
> **快照日期**：2026-11-19 · 随 v1.4.0 PR 一起评审归档；后续版本交付时更新本图。

## 总览

- **产品形态**：H5 移动优先（Vue 3 + Vant）+ 自托管后端（Node.js/Express + TypeORM + MariaDB）+ Docker Compose 一键部署；LLM 集成支持多提供商配置与降级策略，全部调用记账可监控。
- **用户模型**：学生 / 家长 1:1 绑定闭环（学生唯一学习主体，家长全程可见进度明细），管理员负责用户、题库与大模型消耗治理。
- **业务主线**：拍照/手动采集 → 重做（在线 / 拍照手写）→ 卡壳阶梯提示 → 间隔巩固（艾宾浩斯 / FSRS）→ 顽固题预警 → 相似题强化 → 家长周报。

## 入口 2 · 学生端 H5

### 功能域 A：错题采集与录入

| 功能点 | 说明 |
|---|---|
| 拍照/相册单题录入 | 上传题目照片，Vision 模型 OCR 结构化识别（题干/科目/题型/难度/知识点/答案/解析，公式转 LaTeX） |
| 整页多题批量导入 | 整页试卷照片异步识别：立即返回 taskId，前端轮询进度（2s 间隔/10min 超时），多题框选确认后批量入库；无 Redis 自动降级进程内队列 |
| 手动录入 | 不走识别直接手工填写错题（科目/题型/难度/知识点/答案/解析） |
| 题图提取与降级 | 题干结构图形独立裁剪为插图渲染；识别失败自动降级展示局部原图（ADR 0003） |
| 原图折叠防剧透 | 带手写批注的原始照片默认折叠，独立作答前不暴露答案提示 |
| 录入查重防重 | 同学生同学科按题干指纹比对，重复题提示确认（可强制保存） |
| 错因标签标注 | 录入确认页可标注预设错因（审题不清/计算粗心/公式遗忘/方法缺失/其他），后端白名单校验 |

### 功能域 B：重做与掌握跟踪

| 功能点 | 说明 |
|---|---|
| 在线重做 | 键入作答提交，客观题精确文本比对、解答题 LLM 语义判分（部分正确容忍） |
| 拍照手写重做 | 上传手写过程照片，Vision LLM 批改（对错/分数/反馈/置信度） |
| 当天防刷 | 同一题当天（00:00–23:59）仅允许提交一次，提交后输入即刻锁定防答案暴露 |
| 错后错因补标 | 做错后引导勾选错因标签，并入错题画像 |
| 掌握状态机 | 新错题 → 学习中 → 已掌握；间隔复习做错轮次归零、连对达标毕业 |
| 掌握进度页 | 全量题目掌握状态与「第 N/5 轮」展示口径、FSRS 下次间隔天数 |
| 学生改判 | 对判分结果自查后可改判（记录审计轨迹） |

### 功能域 C：阶梯式 3 级提示（v1.4）

| 功能点 | 说明 |
|---|---|
| 3 级渐进提示 | 重做页 LLM 引导按 ① 考点方向 → ② 思路台阶 → ③ 关键方程渐进生成，均不给出最终答案 |
| 逐级解锁 | 第 N 级需先看过第 N-1 级，阻断「卡壳即看解析」 |
| 提示用量记账 | 提示调用按 guidance 场景记录 Token 用量 |
| 完整解析兜底 | 查看完整解析的重做按「未独立掌握」（assisted）记录：不计连对、不推进轮次，次日同轮重试 |

### 功能域 D：复习排程（v1.4）

| 功能点 | 说明 |
|---|---|
| 双调度器可配 | `REVIEW_SCHEDULER=ebbinghaus|fsrs`：静态艾宾浩斯 1/2/4/7/15 天（默认）与 FSRS 动态自适应排程一键切换 |
| FSRS 动态排程 | 按 DSR 记忆模型（难度/稳定性）逐题计算下次间隔：难题加密复习、简单题减少无效轮次；做错次日回落重排 |
| 清本毕业 | FSRS 模式下做对且间隔 ≥ 毕业阈值（默认 30 天）即判定已掌握，移出每日队列 |
| 今日待复习队列 | 学生首页直达，按到期时间驱动（两种调度器共用同一队列口径） |
| 调度器配置下发 | 轮次总数/间隔表由接口下发，学生端展示口径随配置渲染 |
| 回放对比工具 | `npm run replay:compare`：用既有复习记录回放两调度器，对比毕业轮次/天数/冗余复习（FSRS 默认切换依据） |

### 功能域 E：顽固薄弱点预警（v1.4）

| 功能点 | 说明 |
|---|---|
| 自动打标 | 累计做错 ≥ 3 次（可配）且未掌握的错题自动标记「顽固薄弱点」 |
| 学生首页置顶 | 仪表盘置顶预警入口，提示对照教材/找老师定向补课，避免机械重试 |
| 画像页置顶区 | 薄弱点画像页将顽固题独立置顶展示（打标时间/累计错误） |
| 家长周报预警 | 周报页顽固预警卡，附线下定向补课建议 |

### 功能域 F：相似题强化

| 功能点 | 说明 |
|---|---|
| LLM 相似题生成 | 按原题知识点生成相似题（连续错 2 次触发的需求口径，支持手动触发） |
| 相似题列表与练习 | 按原题/按学生浏览相似题，一键进入练习 |
| 适用性标注 | 学生/家长可标记相似题「适用/不适用（附原因）」，不适用题不再推荐 |

### 功能域 G：错题本导出

| 功能点 | 说明 |
|---|---|
| A4 纯题卷导出 | 不含答案与手写笔迹（只用干净题图），适合线下重做 |
| 题卷 + 解析导出 | 附答案与解析版式 |
| 一键打印/存 PDF | 浏览器打印「另存为 PDF」，A4 排版防断页 |

### 功能域 H：统计与报告

| 功能点 | 说明 |
|---|---|
| 周报 | 本周录入/重做/掌握率/相似题生成统计 + 薄弱知识点标签 |
| 统计信息 | 录入总量、重做正确率、掌握分布 |
| 错因画像 | 错因占比 + 薄弱知识点加权画像（学生/家长共用） |
| 日报 | 当日录入/重做/掌握统计 |
